# Chessrankings
This is a fullstack web application displaying the top ranked chess players in the world. Including the player information, games and reviews.

This application lets you easily sift through different players and their stats filtering with search included.

The technologies used are React + vite
Express.js and nodeJS
MongoDB with mongoose

SETUP#
Clone the repository.
Run "npm install"   
create a .env file and add the appropriate credentials
Run "npm run dev" to launch the frontend
and then open your browser on the correct port to have the frontend be displayed.
